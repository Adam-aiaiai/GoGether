# Development plan

## Current MVP

Compose navigation, eight required page flows, mock events/users, create/join/cancel/waitlist/promotion, organizer cancellation, demo check-in, profile switching, and pure JVM business tests.

## Next milestones

1. Confirm product copy, accessibility, empty/loading/error states, and responsive device testing.
2. Add Firebase Auth and emulator-only development environments.
3. Implement Firestore schemas, transactional registration, trusted waitlist promotion, and Security Rules tests.
4. Add notifications, durable check-in/feedback, observability, and privacy review.
5. Add Compose UI tests, integration tests, CI, release signing owned outside the repository, and staged QA.

Real-time chat, payment, AI recommendations and production QR verification are outside this skeleton.
