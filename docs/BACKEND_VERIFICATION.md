## 关键覆盖

- 独立账号注册、资料共享、本人邮箱隔离；真实 Android Repository 登录、退出再登录、离线快照读取与断网写入失败。
- 活动创建、编辑、取消；伪造身份和参与者越权编辑拒绝；时间/地点变更通知和无变化编辑不重复通知。
- 两个客户端争抢最后名额、FIFO 候补、取消自动补位、同 requestId 并发重试、错误复用 requestId 被拒绝；截止时间和缩容边界。
- 公告及引用、提问与组织者回答、消息监听和已读状态；只有收件人能修改已读状态。
- 已提交但响应丢失后：再次报名、取消再报名、新通知“全部已读”、公告重试不重复；resolveRequest 只能查询本人结果。Android 用例通过写入已确认请求的待处理记录模拟丢失响应，再通过真实接口恢复。
- 服务器二维码有效期、报名资格、集合点版本、距离、定位精度/年龄和模拟定位标记；过期或错误码拒绝、重复签到只生成一个结果、组织者出席名单权限。
- 公开匿名与仅组织者可见评价、图片路径归属、重复评价；私密图片不通过公开链接读取，上传封存后旧 bearer URL 无效，重新上传后幂等回放仍撤销新链接。
- 云端签到状态恢复、评价失败保留草稿和成功重试；二维码实际像素可由同一 ZXing 扫描器解码，包含固定失败样本和 64 个变化样本。

## 修复过的联调问题

- Android 17 的本地网络权限：emulator 模式有授权入口，正式 Firebase 模式不申请此权限。
- Android Functions SDK 在本地触发不需要的旧 IID 注册：本地使用带 Auth ID token 的 callable HTTP 协议；正式 Firebase 模式继续使用 SDK。
- 大快照使用只读事务，避免阻塞报名写事务；竞争失败会检查已提交结果并有限重试。
- 已提交带图片活动的重试先回放结果，避免跨过开始时间后被当前时间校验阻断。
- 丢失响应的操作记录区分重试与新的用户意图，防止回放过期报名/已读结果。
- 私密照片封存到服务器私有路径并删除上传暂存文件，包含成功结果回放时的重复清理。
- 账号切换后拒绝旧请求结果，并清理退出账号的离线快照及已恢复的私有结果。
